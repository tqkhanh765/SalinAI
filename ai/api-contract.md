## 3. RAG Search Contract (MongoDB Atlas)

- **Input**: Query vector (Generated by Gemini).
- **Output**: Top-3 guideline chunks (Filtered by `crop_stage`).
- **Minimum Score**: 0.72.

## 4. Operational API Endpoints (Helpers)

While sensor data is handled via Firebase, the following helper endpoints manage system states:

- `PATCH /api/control-mode`: Toggle between `AUTO` and `MANUAL`.
- `PATCH /api/crop-stage`: Update the current life cycle of the crop.
- `POST /api/decision-feedback`: Submit human feedback on AI actions to update **Policy Memory**.
