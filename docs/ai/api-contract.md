# SalinAI v6.0 API Contract

This document outlines the core REST API endpoints available in SalinAI v6.0 for farm operations, AI interactions, and hardware integrations.

## Base URL
All API paths are relative to `http://localhost:3001` in development.

## 1. Core Data Ingestion & State

### `POST /api/ingest` (or `/api/sensor-data`)
Ingest raw sensor data from ESP32 or simulated hardware. Triggers the AI Orchestrator loop if conditions change significantly.
- **Rate Limit:** 60 requests per minute
- **Body:**
  ```json
  {
    "salinity": 4.5,
    "moisture": 45.2,
    "crop_stage": "VEGETATIVE",
    "external_forecast": {
      "rainfall_24h": 0,
      "temperature": 35,
      "tide_status": "RISING"
    }
  }
  ```
- **Response (200 OK):**
  ```json
  { "status": "OK", "message": "Data ingested successfully" }
  ```

### `GET /api/farm-state`
Fetch the current state of the farm including sensors, actuator, AI status, and recent action logs.
- **Query:** `?logLimit=10` (default 50)
- **Response (200 OK):**
  ```json
  {
    "sensorData": { ... },
    "actuator": { "valve_state": "OPEN", "control_mode": "AUTO" },
    "aiStatus": { "is_processing": false, "last_reasoning": "..." },
    "actionLogs": [ ... ]
  }
  ```

## 2. AI Intelligence & Planning

### `POST /api/evaluate-feedback`
Submit farmer feedback for a specific AI decision. Triggers the Evaluator Agent to learn from mistakes.
- **Body:**
  ```json
  {
    "action_log_id": "log_12345",
    "verdict": "incorrect",
    "notes": "Too hot, should close valve to save fresh water."
  }
  ```
- **Response (200 OK):**
  ```json
  {
    "status": "OK",
    "lesson": {
      "condition_pattern": "...",
      "lesson_text": "..."
    }
  }
  ```

### `GET /api/lessons-learned`
Retrieve the latest lessons extracted by the Evaluator Agent.
- **Query:** `?limit=10`
- **Response (200 OK):** Array of lesson objects.

### `GET /api/irrigation-plan`
Fetch the 5-day proactive irrigation plan generated by the GLM-4.7 Planner Agent.
- **Response (200 OK):**
  ```json
  {
    "created_at": "...",
    "plan": [
      { "date": "2026-05-03", "risk_level": "Cao", "recommendation": "..." },
      ...
    ]
  }
  ```

### `POST /api/irrigation-plan/trigger`
Manually trigger the generation of a new 5-day irrigation plan.
- **Response (200 OK):** Generated plan array.

### `GET /api/policy-summary`
Retrieve the current consolidated policy memory that the AI uses as its operating guidelines.
- **Response (200 OK):** `{ "summary": "...", "stats": { ... } }`

## 3. Streaming & System Health

### `GET /api/health`
Check backend server, MongoDB, and Firebase connectivity.
- **Response (200 OK):**
  ```json
  {
    "status": "OK",
    "timestamp": "2026-05-02T12:00:00Z",
    "firebase": "CONNECTED",
    "mongodb": "CONNECTED",
    "last_ai_run": 1700000000000
  }
  ```

### Socket.io Stream (`ai_token`, `ai_status`)
For real-time terminal UI text streaming.
- **Events Received:** `ai_token` (contains character chunks), `ai_status` (contains state changes).

### `GET /api/farm-stream`
Server-Sent Events (SSE) endpoint to stream real-time updates for `sensor_data` and `actuator` states.
